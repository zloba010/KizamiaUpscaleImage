# 📦 Установка расширения

Чтобы установить проект, выполните 4 простых шага.

<div align="center">

| Шаг | Действие | Важное |
| :--- | :--- | :--- |
| **1️⃣** | **Скачайте архив** | [💾 Скачать с Яндекс Диска](https://disk.yandex.ru/d/xBsCW3dOkPeV2Q) |
| **2️⃣** | **Распакуйте файлы** | Выберите любую удобную папку. <br> *Запомните путь к ней!* |
| **3️⃣** | **Включите режим разработчика** | Меню: `Расширения` → `Управление расширениями` <br> ⚙️ Активируйте тумблер в углу. |
| **4️⃣** | **Загрузите папку** | Кнопка: **«Загрузить распакованное расширение»** <br> Укажите путь к папке из Шага 2. |

</div>

> [!SUCCESS]
> Готово! Расширение установлено. Проверьте, что статус плагина — «Активен».

> [!WARNING]
> ⚠️ Не удаляйте папку с файлами после установки — браузер читает расширение прямо из неё.
